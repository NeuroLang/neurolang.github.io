neurolang.utils.engine_registry#

Declarative engine registry for the neurolang-query CLI.

Engines are declared in engines/engines.yaml. Each engine may define:

  • a Python initialisation script (python_init);

  • optional Datalog initialisation code (datalog_init) evaluated after the Python script;

  • optional CSV/TSV relations (relations) loaded as extensional predicates after the Datalog init. Each relation entry may carry optional name and description fields for predicate metadata used by the --list-predicates command. The file value may be a URL (http:// / https://) for automatic download;

  • downloads — files to fetch (with optional archive extraction);

  • templates — neuroimaging templates (brain masks, anatomical templates) downloaded via nilearn or TemplateFlow (if the templateflow package is installed). Each template may optionally register a voxel(i, j, k) predicate from its non-zero mask:

    templates:
  mni_brain:
    source: nilearn
    variant: brain_mask
    predicate: voxel
  t1_ref:
    source: templateflow
    template: MNI152NLin2009cAsym
    resolution: 1

  • ontologies — OWL/RDF ontologies to load from URLs or local paths;

  • builtins — list of known function names (exp, log, startswith, etc.) to register as callable symbols;

  • probabilistic_choice — uniform probabilistic choices declared as name: {source: other_predicate}.

  • atlases — brain atlases downloaded via nilearn (e.g. destrieux, schaefer, difumo) and registered as predicates with ExplicitVBR regions. Deterministic atlases use ExplicitVBR.from_spatial_image_label; probabilistic atlases are thresholded (default 0.5) to create binary region masks.

  • text_embeddings — semantic search over document texts (e.g. PubMed abstracts) with SPECTER2, registered as a function f(query, doc) -> similarity; see neurolang.utils.text_embeddings:

    text_embeddings:
  study_abstracts:
    ids_from: study
    source: pubmed
    function: query_similarity

Usage#

from pathlib import Path
from neurolang.utils.engine_registry import (
    build_engine,
    show_engines,
    list_engine_names,
    get_engine_config,
)

# Load engine from the built-in YAML
nl = build_engine("neurosynth", data_dir=Path("data"))

# Load engine from a custom YAML file
nl = build_engine("my_engine", yaml_path=Path("my_engines.yaml"),
                  data_dir=Path("data"))

# Print available engines with descriptions
show_engines()

# List engine names from a custom YAML
for name in list_engine_names(yaml_path=Path("my_engines.yaml")):
    print(name)

class neurolang.utils.engine_registry.Sort(name, columns, type='', description='', space='', grid='')#

A sort of entities an engine declares once, in its sorts section.

Its entities span columns, whose values are of the type; a sort of N > 1 columns reads in ND in SQUALL (every Voxel in 3D).

The space of a sort of points tells what its columns are: voxel for the indices (i, j, k) of a grid, mm for coordinates (x, y, z) in millimetres in the space of the engine’s template, "" otherwise. The grid of a sort of voxels is the grid it indexes: that of the engine’s template (see build_engine()) when "" or template, else that of the atlas of this name.

neurolang.utils.engine_registry.build_engine(name, data_dir, resolution=None, yaml_path=None)#

Create and populate a NeurolangPDL engine from its declarative YAML config.

Parameters:
name

Registered engine name (e.g. "neurosynth", "destrieux").

data_dir

Directory under which downloaded data is cached.

resolution

If set, resample the MNI mask to the given isotropic resolution (mm).

yaml_path

Path to an engine YAML file. Defaults to the built-in engines/engines.yaml.

Returns:
NeurolangPDL

A fully initialised engine ready for query execution. Its template attribute is the MNI image whose grid the voxel indices of the engine refer to (the sorts of space: voxel), resampled to resolution if given, or None if the engine does not require the MNI mask. Its grids attribute holds the images of the grids voxel indices may index, by name: the template, as template, and each atlas, under its name (the sorts naming a grid).

Raises:
ValueError

If name is not a registered engine.

ImportError

If the engine’s Python init module cannot be loaded.

Parameters:

  • name (str)

  • data_dir (Path)

  • resolution (Optional[float])

  • yaml_path (Optional[Path])

Return type:

NeurolangPDL
