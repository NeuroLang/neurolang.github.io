neurolang.utils.cli#

Command-line interface for NeuroLang query execution.

Provides a neurolang-query command that initializes a NeuroLang engine from the engine registry and executes Datalog queries from arguments, files, or standard input.

Usage#

# List available engines
neurolang-query --list-engines

# Print the SQUALL grammar and parser metadata as JSON
neurolang-query --grammar-json

# List predicates for an engine
neurolang-query --engine neurosynth --list-predicates

# List RA sets for an engine
neurolang-query --engine neurosynth --list-sets

# Inline query
neurolang-query "ans(t) :- term_in_study_tfidf(s, t, w)"

# Query from file
neurolang-query -f query.dl

# Query from stdin
echo "ans(t) :- term_in_study_tfidf(s, t, w)" | neurolang-query

# Destrieux atlas engine
neurolang-query --engine destrieux "ans(name) :- destrieux(name, region)"

# Squall (controlled English) query
neurolang-query --squall "obtain every peak_reported."
neurolang-query --squall -f query.squall

# Show the Datalog IR for a SQUALL query (no execution)
neurolang-query --squall --show-datalog "obtain every Voxel in 3D that a Study reported."

# Show the relational algebra plans of a query (no execution)
neurolang-query --show-ra "ans(x) :- P(x)"

# ... annotated with the number of rows each plan node produces
neurolang-query --show-ra --ra-analyze "ans(x) :- P(x)"

# Interactive REPL (needs ``pip install "neurolang[tui]"``)
neurolang-query -i --engine neurosynth

# ... or run REPL statements and dot-commands from a pipe
echo 'ans(x) :- study(x)' | neurolang-query -i

neurolang.utils.cli.report_error(exc, program, *, squall, debug, nl=None, file=None, engine_name='')#

Print the query error exc as a formatted message.

The message shows the location of the error in program, hints and the symbols of the engine nl close to an unknown one. When the error concerns a predicate of the engine engine_name that spans entities of several columns, a note tells how to write it (see sort_notes()). In debug mode the traceback is printed first; otherwise unexpected errors get a hint to use --debug. file defaults to sys.stderr.

neurolang.utils.cli.squall_column_names(engine_name, program, relations=None, rules=())#

Return column names for the results of a SQUALL program’s queries.

SQUALL names the columns of most results after fresh variables. The result is a dict from the key of each obtain (as in the results of execute_squall_program()) to the names of its columns:

  • obtain every R. takes the columns of R: those the engine configuration declares, those relations (a dict from relation names to their columns) gives, or those of the rules defining R, in the program or among rules, the rules defined before;

  • otherwise, a column is named after the user’s variable (?s), the aggregate (count), the as name of a single column, the probability, or the column of the first relation of the body its variable is in (i, j, k for every Voxel in 3D); an undeclared unary relation names its column after itself.

Parameters:

  • engine_name (str)

  • program (str)

  • relations (dict | None)

Return type:

dict
